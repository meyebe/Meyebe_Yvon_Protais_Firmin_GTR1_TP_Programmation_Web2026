Introduction

Ce mini-site a été créer dans le cadre du cours de TP programmation web.

Il permet de découvrir la création de plusieurs pages HTML reliées entre elles.

Obectif du mini-site

L'objectif est d'apprendre à structurer un petit projet web avec plusieurs fichiers.

Pages disponibles

  • La pages Accueil Présente le contexte général du mini-site.
  • La page Présentation contient les informations présonnelles de l'etudiant.
  • La page Contact contient les informations de contact de l'etudiant
